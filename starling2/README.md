# 2026-10-22 Starling2探索飛行の解析記録

## 収録結果

2026-10-22のStarling2による約4mの探索飛行を対象とした、RealSense深度・カラー画像と飛行ログの追加解析です。

- 深度64フレームから復元・累積した646,636点（1cmボクセル）
- YOLOによる花候補1,031観測を、最大点間距離6cmの条件で58群に統合
- 花候補中心から3cm以内の2,826点を赤く表示
- 342枚の元カラー画像と検出枠を照合可能
- 初期表示はRGB色付き、灰色へ切替可能

## 操作

| 操作 | 内容 |
|---|---|
| 赤い点・候補中心をクリック | 元カラー画像・検出枠・拡大画像を表示 |
| 画像欄の前後ボタン・観測一覧 | 同じ候補群の別時刻の観測に切替 |
| 候補群の一覧 | 群IDを指定して選択 |
| 左ドラッグ | 点群を回転 |
| 右ドラッグ、またはShift＋ドラッグ | 表示を平行移動 |
| ホイール | 拡大・縮小 |
| 全体表示 | 視点と拡大率を初期状態へ戻す |
| 画像欄を隠す | 点群を横幅いっぱいに表示 |
| 候補中心をOFF | 遮蔽物の手前にも表示する中心マーカーを隠す |

## 解析条件と注意点

深度画像を校正情報で3次元点へ変換し、深度→カラーの外部校正によりRGBを付与しました。
画像時刻と飛行ログの計測時刻を合わせ、機体位置・Quaternion姿勢・カメラ取付値で点群と花候補を共通座標へ変換しています。
取付は機首方向・水平、前方3cm・上方3cmの概測値です。

表示座標は探索進行方向・その左・上です。高さは探索開始時の機体基準で、地面からの高さではありません。
ENUの元座標もVIOのローカル座標系であり、測量座標ではありません。

**58群は実際の花58個を意味しません。** 誤検出・背景深度・別の花の混在・同一花の分割があり得ます。
赤色は候補位置の周囲3cmを示し、花びらの領域分割ではありません。
候補中心マーカーは選択しやすいよう遮蔽物の手前にも表示します。
同じ深度から作った点群との一致は独立した精度検証になりません。真値との位置精度評価は未実施です。
この結果をそのまま実機飛行・受粉の指令点には使用しないでください。
